# CodeAlpha_Unemployment_Analysis
Data analysis project that explores unemployment rates across different states using Python with data visualization and insights.

# Unemployment Analysis 📊

## Overview
This project analyzes unemployment rates across different states using Python and data visualization techniques.

## Features
- Data visualization using bar chart, pie chart, histogram  
- Comparison of unemployment rates across states  
- Identification of highest and lowest unemployment states  

## Tools Used
- Python  
- Pandas  
- Matplotlib  
- Seaborn  

## Output
- Bar chart showing unemployment by state  
- Pie chart showing distribution  
- Histogram for data distribution  
- Printed analysis of highest and lowest unemployment  

## Conclusion
This project demonstrates how data analysis and visualization can help understand unemployment trends.
