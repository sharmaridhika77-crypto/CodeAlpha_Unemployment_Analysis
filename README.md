# CodeAlpha_Unemployment_Analysis
Data analysis project that explores unemployment rates across different states using Python with data visualization and insights.

# Unemployment Analysis 📊

This project analyzes unemployment rates across different states using Python.

## Features
- Data visualization using bar chart, pie chart, histogram
- Comparison of unemployment rates
- Identification of highest and lowest unemployment states

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn#
